# Historical offline audio previews

©2026 Adrian Vos(soveda), MIT for original rendering code/documentation. These
WAVs were rendered offline from early alpha DSP, not recorded from hardware and
not previews of current beta3. They remain for historical comparison only.
Measured-filter previews derive from Bill Gardner and Keith Martin, MIT Media
Laboratory1994, KEMAR Technical Report280; separate measurement terms remain in
[the data notice](../../vendor/KEMAR/SOURCE_TERMS.md). Earlier analytic previews
predate that measured bank. [Project attribution](../../THIRD_PARTY_NOTICES.md).
The original filenames and audio bytes are preserved; [checksums](SHA256SUMS.txt).
Historical rendering code remains in tools/ and archived snapshots.
